① E₁ = A·η·G·365·PR·(1+γΔT) 연간 발전량
무슨 공식? 1년 동안 패널이 뽑을 수 있는 에너지의 이론 최대치. 궤도에서 실제로는 Eclipse 때문에 더 작아져서 시뮬 평균전력으로도 한번 더 계산해 비교함.
변수의미시뮬에서 어디?
A패널 면적 m²패널 면적 입력
η셀 효율 (eta0)셀 타입 선택하면 자동 - 예: Si 22%, III-V 32%
G일사량 W/m²일사량 입력 (우주=1361, 지상=1000)
PR성능비 (손실계수)PR 입력 0.8 기본
γ온도계수 beta셀 DB에 내장 (-0.0021 ~ -0.0045)
ΔT온도차 (T-25°C)시뮬 열 모델에서 자동 계산된 평균온도
사용법: 면적 20m², Si(η22%), G1361, PR0.8, γ-0.0045, ΔT 30K면
E₁ = 20×0.22×1361×365×0.8×(1-0.0045×30) /1000 ≈ 1,520 kWh/년
실제 시뮬에서는 avg_power × 24×365 /1000 으로도 계산해서 두 값을 결과창에 같이 보여줌.
② E(t)=E₁·(1-d)^(t-1) 열화 반영 발전량
무슨 공식? 매년 패널이 조금씩 망가지는 걸 반영. t년차 발전량은 첫해의 (1-열화율) 거듭제곱.
변수의미시뮬에서 어디?
d연간 열화율셀마다 다름 - Perovskite 2%, Si 0.7%, III-V 0.5%
t운영 연차 1~N수명 입력 (15~25년)
사용법: Si d=0.007이면 10년차는
E(10)=E₁×(0.993)^9 ≈ E₁×0.939 (6.1% 감소)
결과창의 25년 곡선 그래프에서 Perovskite가 빨리 떨어지는 걸 바로 확인할 수 있음. 장기 임무면 d가 낮은 III-V/HJT 선택.
③ LCOE = ΣCₜ/(1+r)^t / ΣEₜ/(1+r)^t 균등화 발전비용
무슨 공식? 평생 동안 1kWh 뽑는데 진짜 얼마 드는지. 낮을수록 좋은 전지. 모든 비용과 발전을 할인율 r로 현재가치화해서 나눈 것.
변수의미시뮬에서 어디?
Cₜt년차 비용t=0: CAPEX+생산비+발사비+설치, t>0: 유지비
Eₜt년차 발전량위의 E(t)
r할인율할인율 입력 5% 기본 - 높을수록 미래 가치 낮게 봄
사용법: 결과의 [비용 구조]에서 확인.
LCOE $0.08/kWh인데 전기요금이 $0.15면 이득. 전기요금보다 LCOE가 낮아야 경제성 있음.
팁: 발사비 $/kg가 20000에서 5000으로 떨어지면 LCOE가 절반으로 떨어지는 걸 시뮬에서 바로 볼 수 있음. 단일 전지 최적화에서 objective를 최소 LCOE로 놓고 돌리면 LCOE가 가장 낮은 고도/경사를 찾아줌.
④ NPV = Σ(Vₜ-Mₜ)/(1+r)^t - CAPEX 순현재가치 - 최종 결론
무슨 공식? 이 사업이 평생 동안 벌어들이는 순이익을 지금 돈으로 환산. NPV>0이면 투자할 가치 있음. 이 시뮬의 최종 결론 지표.
변수의미시뮬에서 어디?
Vₜt년차 경제적 가치Eₜ × 전기요금 × (1+상승률)^(t-1)
Mₜ유지비연간 유지비 입력 또는 CAPEX %
CAPEX초기 투자패널+생산+발사+설치+인버터 합계
사용법 - 워크플로우:
1. SIM 실행 → 결과에서 NPV, 회수기간 확인
2. NPV가 음수면? 전기요금 올려보거나 발사비 낮춰서 민감도 분석 (결과창 [가치 변동] 테이블)
3. ① 단일 전지 최적화 → objective를 최대 NPV로 → 가장 돈 많이 버는 궤도 찾음
4. ② 전체 셀 비교 → 현재 환경에서 8개 셀 중 NPV 1등 확인
5. 각 셀의 최적 환경 찾기 → 셀별로 가장 잘 버는 고도/경사 확인 → "Si는 500km 45°에서 최고, Perovskite는 저고도 단기 임무에서 최고" 같은 결론 도출
NPV = $12,340, 회수 6.2년이면 6.2년 이후부터 순수익.
💡 빠른 사용 팁:
• 가격은 셀 이름 옆에 바로 표시됨 (예: Perovskite - $95/m²)
• 모든 결과는 [② 결과 패널]에 INPUT+OUTPUT 같이 저장되어 TXT로 다운 가능
• 최적화는 Type A=한 전지의 최고 효율 궤도, Type B=여러 전지 중 환경별 최고 전지
